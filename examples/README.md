# A reproducible example

These files use the same **synthetic bicycle-trip data** as the starting editor.
They do not represent an observed city or a real-world measurement.

- [bicycle-trips.csv](bicycle-trips.csv): six rows; comma separator, decimal-dot
  values, year as the label, and `thousand trips` as the unit.
- [bicycle-trips.narraplot.json](bicycle-trips.narraplot.json): an editable project
  saved by the working app. Use **Open project** to load a downloaded copy.
- [bicycle-trips.html](bicycle-trips.html): the three-scene story exported by the
  working app. Download the file and open it directly in a browser; it works
  offline and includes its data and navigation.

The overview, focus, and takeaway share the same dataset and scale. The focus
identifies 2024 as the largest value in this illustrative table. The final scene
is an editable writing prompt, not a real-world conclusion.
